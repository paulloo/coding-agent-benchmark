# 任务：独立交付 CSV 导出功能

你现在是 DogWalk 项目的独立技术负责人。产品经理提出了以下需求：

用户希望能够导出自己的遛狗历史记录，以便保存和分享。

## 产品要求

1. 支持导出 CSV 文件。
2. 支持导出当前筛选条件下的记录。
3. 可以选择导出的时间范围。
4. 文件需要包含狗狗名称、遛狗日期、开始时间、结束时间、时长、距离和备注。
5. 文件应使用 UTF-8 编码，保证中文在 Excel 中正常显示。
6. 必须防止 CSV Formula Injection。
7. 只能导出当前用户有权访问的数据。
8. 需要考虑大量记录时的性能问题。
9. 导出文件名应包含日期范围。
10. 移动端也应能正常触发下载。

## 你的工作

- 自主理解现有项目架构。
- 制定合理的实现方案。
- 完成前端和后端开发。
- 完成必要的数据库查询。
- 编写自动化测试。
- 检查安全问题。
- 运行类型检查和测试。
- 修复开发过程中发现的问题。

## 执行原则

- 不要只提供计划，必须实际完成代码。
- 不要随意重构无关模块。
- 不要引入不必要的依赖。
- 遇到非关键决策，自己根据项目现有规范判断。
- 遇到真正无法确定的关键业务问题，再提出询问。

## 最终交付

1. 可用的 CSV 导出功能。
2. 通过的自动化测试。
3. 完整的 Git Diff。
4. 实现说明。
5. 已知限制。
6. 是否可以合并的结论。

未经允许不要推送远程仓库或部署生产环境。
