# 任务：实现高品质 DogWalk Dashboard

请为 DogWalk 开发一个高品质的宠物遛狗管理 Dashboard 页面。

## 设计方向

现代 SaaS 产品设计，温暖、简洁、具有亲和力。

## 视觉规范

| 用途 | 值 |
|---|---|
| 主背景 | #F8F7F2 |
| 主文字 | #252820 |
| 主强调色 | #5B8C69 |
| 卡片背景 | #FFFFFF |
| 辅助色 | #E8EFE5 |
| 圆角 | 16px |

- 使用清晰的字体层级。
- 阴影克制，避免过度装饰。
- 不使用大面积渐变和玻璃拟态。

## 页面布局

1. 左侧导航栏。
2. 顶部欢迎区域。
3. 当前狗狗档案卡片。
4. 本周遛狗统计。
5. 最近遛狗记录列表。
6. 每周遛狗时长趋势图。
7. 快捷新增遛狗记录按钮。

## 交互要求

- 切换狗狗时，相关统计和记录同步变化。
- 日期筛选可以正常使用。
- 点击记录可以查看详情。
- 新增记录可以打开表单。
- 所有按钮必须有真实交互。
- 页面必须适配移动端。

## 工程要求

- 优先复用项目已有组件和设计令牌。
- 不要使用静态图片伪造功能。
- 不要使用硬编码的假统计数据。
- 使用真实 API 数据。
- 不允许出现无效按钮和无效链接。

## 完成后

使用 Playwright 打开页面：

- 检查桌面布局。
- 检查移动端布局。
- 检查控制台错误。
- 截图保存最终结果。

在最终报告中说明复用了哪些组件、新增了哪些组件、以及截图路径。
